# Sect Idle — Sketchware Pro V7.0.0 Compatible Project Export

Proyek ini disiapkan secara khusus untuk di-import atau disalin langsung ke **Sketchware Pro V7.0.0**.

## Struktur Proyek:
- `src/main/java/` : Source code Java murni (100% tanpa lambda, method reference, stream API, atau keyword `var`).
- `src/main/res/` : Resource XML, drawable, mipmap, layout, dan raw audio.
- `src/main/assets/` : Asset tambahan game.
- `src/main/AndroidManifest.xml` : Manifest Android dengan pendaftaran Activity dan Permission.

## Kompatibilitas Perangkat:
- Target Minimum: Android 5.0 (API 21)
- RAM Minimum: 1 GB (Termasuk perangkat low-entry seperti itel A70, Mali GPU, dsb)

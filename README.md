# ⚡ Sect Idle / Nusa Legends — Xianxia Idle Cultivation RPG

A comprehensive idle sect management and cultivation simulation RPG rewritten as a responsive React + TypeScript application powered by Tailwind CSS, Web Audio API synthesis, and the Chimera multiplatform build pipeline.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 🌟 Core Features Ported

1. **Sect Management & Economy**:
   - Multi-tier resource ecosystem: Spirit Stones, Celestial Jade, Primordial Essence, Spirit Herbs, and Spirit Ores.
   - Interactive 2D pavilion world layout: Main Sect Hall, Dao Library, Alchemy Lab, Spirit Forge, Herb Garden, Spirit Mine, Sect Bazaar, and Martial Arena.
   - Dynamic real-time calendar (Years, Months, Days, Hours, Seasons: Spring, Summer, Autumn, Winter) with seasonal crop multipliers.

2. **Disciple Lineage & Autonomous AI Workforce**:
   - 14 cultivation realms from Mortal to Heavenly Dao.
   - 7 core Dao attributes: STR, AGI, INT, LCK, VIT, WIS, CHA.
   - Elements (Fire, Water, Wood, Metal, Earth, Light, Shadow, Wind, Ice, Lightning) and Talents (Body Tempering, Mind Clarity, Spirit Resonance, Heaven Decree, etc.).
   - CultivationAiEngine: 1-click autonomous AI task assignment optimizing workforce based on disciple affinities.
   - Spiritual fairy companions (Snow Sprite, Jade Butterfly, Lotus Spirit) granting cultivation and work efficiency buffs.

3. **ATB Turn-Based Combat Arena**:
   - Dynamic Active Time Battle (ATB) gauge simulation with speed scaling (1x, 2x, 4x).
   - Elemental Resonance: +15% team ATK/DEF buffs when matching element disciples spar together.
   - Martial Arts 10-Hit Aerial Juggle Combos and Desperation Qi Clashes (< 25% HP).
   - Heavenly Execution finishers when demonic horde bosses and corrupted fiends are vanquished.

4. **Sect Warfare & Conquest**:
   - Lead sect expeditions against rival sects (Blood Demon Sect, Nine Nether Palace, Celestial Sword Sect, Thunder Cloud Pavilion, Asura Valley, Myriad Beast Manor).
   - Three campaign intensities: Border Skirmish / Raid, Fortress Assault, and Total Sect Annihilation.
   - Plunder enemy mountain vaults for Spirit Stones, Herbs, Ores, and Celestial Jade.

5. **Grand Sect Arena Tournament**:
   - Enter your strongest champions into 1v1 elimination stages (Bronze, Silver, Gold Grandmaster tiers).
   - Critical Dao Strikes, audience reputation gains, and tournament prize pools.

6. **Interactive Fruit-Slash Mini-game**:
   - Swipe & slice spiritual herbs and alchemy ingredients in real time.
   - Multi-hit combos, particle bursts, and demonic bomb hazards directly boosting garden yields and cauldron concoctions.

7. **Heavenly Lightning Tribulation Deflection**:
   - Overcome celestial tribulation lightning strikes using an Aegis barrier shield to breakthrough realm bottlenecks.

8. **Cauldron Alchemy & Fluctuating Bazaar**:
   - Concoct 7 tiers of longevity pills (Qi Gathering, Foundation Establishment, Nascent Soul, Immortal Ascension Pellets) with High and Supreme Grade cauldron outcomes.
   - Trade commodities on the Sect Bazaar with fluctuating market supply and demand.

9. **Civilization Dao Research Tech Tree**:
   - Advance through Mortal, Qi Refining, Core Formation, and Immortal Ascendance eras to unlock automated arrays.

10. **Sect Ascension (Prestige)**:
    - Reincarnate with permanent revenue and disciple combat multipliers powered by accumulated Ancestral Essence.

11. **Chimera Build Engine Studio**:
    - Interactive 1-click multiplatform console packager (PS2 ISO, PSP EBOOT, PS Vita VPK, Switch NSP, NDS ROM, PS3 PKG, and Desktop native binaries).

12. **Authentic Web Audio Synthesizer**:
    - Procedural Guzheng melodies, sword clashes, critical slashes, thunder strikes, and breakthrough fanfares.

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start Vite development server (Port 3000)
npm run dev

# Compile production bundle
npm run build

# Run TypeScript checks
npm run lint
```

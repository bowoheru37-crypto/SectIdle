# 🛡️ SECURITY POLICY

## Reporting Vulnerabilities

We take the security of **Sect Idle** and the **Chimera Unified SDK** seriously. If you discover a security vulnerability, please follow these steps:

1. **Do NOT open a public issue.**
2. Email the maintainer directly or send a private security advisory via GitHub.
3. Include detailed steps to reproduce the issue.

We will review reports promptly and publish patches in a timely manner.
